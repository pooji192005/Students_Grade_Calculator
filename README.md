# 🎓 Student Grade Calculator (Python)

## 📌 About
The Student Grade Calculator is a beginner-friendly Python project that calculates total marks, average score, and assigns a grade based on marks entered for multiple subjects. This project demonstrates core Python programming fundamentals and is suitable for portfolio use.

---

## ✨ Features
- Accepts marks for multiple subjects
- Calculates total and average marks
- Assigns grades based on average score
- Simple command-line interface

---

## 🧠 Concepts Used
- Functions
- Loops
- Conditional statements
- User input and output
- Basic arithmetic operations

---

## 🧮 Grading Criteria
| Average Marks | Grade |
|--------------|------|
| 90 and above | A    |
| 75 – 89      | B    |
| 60 – 74      | C    |
| 40 – 59      | D    |
| Below 40     | Fail |
